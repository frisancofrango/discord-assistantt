Autenticação com Token Bearer

REST API v2

Todas as requisições à API devem incluir seu token no cabeçalho Authorization: Bearer lp_sec_....

curl -X POST https://api.loopbot.app/v2/orders \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"productId": "vip-mensal", "userId": "1536902502870421544"}'
